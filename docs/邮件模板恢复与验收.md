# 邮件与公共模板恢复

页面已移除“开发预览”“开发联调”“开发版可用”和模拟服务提示，工具状态显示“可使用”。本轮仍只操作 3200 / 3201 开发服务；真实付费生图接口未启用，界面文案清理不代表上线或切换供应商。

平台 SMTP 来自 Yinglan 原开发数据库中的邮件配置，由 Yinglan 导出工具仅读取本工具开发数据，经权限 0600 的临时传递文件交给平台，使用平台密钥重新加密后删除临时文件。没有读取或修改生产目录、配置或数据库。真实 SMTP 连接、TLS 与身份认证验证通过。外部邮件是否进入收件箱须以实际收件确认为准。

常规开发启动按 `dev-runtime/preferences.json` 的 `mail_transport: smtp` 使用真实邮件。测试合成 `.test` 用户时必须显式用 `BIOHUB_MAIL_TRANSPORT=capture` 启动开发平台，测试结束后恢复普通启动。集成测试有 capture 模式前置检查，防止向合成地址真实发信；SMTP 单元测试使用临时本地邮件服务器覆盖实际注册及密码重置邮件发送、验证码、单次重置令牌与加密配置。

FigureLabs 公共模板已恢复 54 条、9 个分类；启动脚本检测缺失模板并按稳定 ID 补齐，不导入旧账户的个人模板，不覆盖当前个人作品和任务。原开发数据保持原有归属。
