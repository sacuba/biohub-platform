# 用户积分与自动登录修复

用户要求先开发验证再更新生产。管理员用户列表新增积分余额列，显示可用与冻结积分，和钱包桶、有效期及冻结记录保持一致；查询不增加积分、不改变到期流水。积分调整后列表重新加载，管理员权限校验保持。

公共契约在 0.1.0 增加兼容的 AdminUser 响应字段 available_credits / frozen_credits，仅管理员列表使用；User 身份响应不增加余额。同步生成两应用客户端和摘要。

Yinglan 平台模式等待身份配置与会话读取后，未登录自动前往 /api/platform/login，再按 OIDC/PKCE 跳转平台登录并保留回到工具的流程。退出后回平台首页，避免刚退出又自动触发工具登录。独立模式保留原登录表单。

开发验证：平台 15 项单测、Yinglan 46 项回归、契约检查、两项目 lint / typecheck / build 通过；新增浏览器检查覆盖余额与数据库计算一致、未登录自动跳转、游客无法读取用户积分、手机布局；现有 8 项导航验收通过。生产更新前联合备份并排空任务，保持现有数据库与凭据；更新后运行同一只读余额/跳转浏览器检查。
