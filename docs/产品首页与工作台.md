# 产品首页与工作台

首页 `/` 用于了解产品与发现工具，使用顶部导航，没有工作台侧栏。即使已登录，访问首页依然显示产品内容，并在顶部提供“进入工作台”。工具目录、平台优势、使用步骤和常见问题均可公开浏览；五个待开发工具无可执行入口。首页科研插画为自有 SVG 示意图，不是生图效果样张。

工作台 `/workspace` 负责个人操作：工具大厅、我的任务、积分中心、个人账户及管理后台。工具大厅保留搜索、分类和工具入口，移除首页宣传大图。账户等子页面使用 `/workspace?view=account`、`/workspace?view=credits`、`/workspace?view=tasks`；旧 `/?view=...` 入口兼容转入此处。

| 入口 | 登录完成后的去向 |
|---|---|
| 首页“登录账号” | 工具大厅 `/workspace` |
| 首页“创建账户” | 双密码注册、邮箱验证码验证，再登录进入工作台 |
| 游客点击可用工具 | 保留工具选择，登录后直接进入工具的 OIDC 流程 |
| 已登录点击工具 | 直接进入工具，无需重新输入密码 |
| 直接打开工作台账户或积分链接 | 未登录显示登录引导，登录后返回对应页面 |
| 工具发起 OIDC 登录 | 保留经过限制的 `/interaction/...` 路径，完成工具授权 |
| 退出平台 | 撤销全平台会话并回到公开首页 |

Yinglan 的“返回工具大厅”、平台账户和积分链接现在直接指向 `/workspace`。本次仅调整开发前端与文档，没有修改认证协议、钱包计费、生产配置或生产数据。

验证：平台 lint、typecheck、build、12 项业务测试与契约漂移检查通过；原 22 项联调通过；新增 8 项浏览器导航检查覆盖首页与工作台分离、取消工具选择、登录去向、工具直达、OIDC 发起登录、旧链接与刷新、游客访问工作台、手机导航和退出。Yinglan lint、typecheck 通过。截图在忽略提交的 `test-results/product-home-desktop.png`、`product-home-mobile.png` 和 `product-workspace-desktop.png`。

AbTrace 开发接入后，工具大厅增加可执行的 Sanger 抗体分析入口（3202），展示“免费 · 本地抗体分析”。Yinglan 仍展示原图像价格；后台逐工具独立编辑权限并保留其他工具角色。五个原占位工具保持待开发。
