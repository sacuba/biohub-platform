# 首版开发验收记录

本轮只建设开发平台和 Yinglan 联调，未执行生产发布、真实用户迁移、真实 SMTP 发信或付费模型请求。平台与 contracts 为独立本地 Git 仓库；根目录没有建立总仓库。

## 验证结果

| 检查 | 结果 |
|---|---|
| contracts OpenAPI、Schema、工具清单、钱包/任务请求响应样例 | 通过 |
| platform / yinglan 生成客户端版本及摘要漂移 | 通过，0.1.0 |
| platform lint、typecheck、build | 通过 |
| platform 钱包、验证码、路径保护测试 | 12 / 12 |
| Yinglan lint、typecheck、build | 通过 |
| Yinglan 回归（独立模式 40 项 + 平台钱包恢复 6 项） | 46 / 46 |
| 平台与工具实际浏览器联调 | 22 / 22 |
| 实际开发进程停止、重启与平台短暂中断 | 4 / 4 |

Yinglan 构建有既有 ESLint Next 插件提示，构建及独立 lint 均通过。未设置 ignoreBuildErrors。

浏览器联调覆盖 OIDC / PKCE 登录、用户映射、双密码注册、邮箱验证码、原密码改密、单次密码重置、平台/工具全平台退出、账号停用、工具权限撤销、平台与工具管理员权限隔离、兑换批次关键词及兑换用户、活动售价/余额共享、每日赠送去重、成功与编辑扣费、幂等、失败与取消释放、取消后的迟到结果、并发防透支、任务与私有图片越权、服务身份作用域、CSRF 与来源、手机页面、游客搜索空状态和弹窗键盘操作。

钱包恢复测试使用可控模拟平台，验证冻结成功但响应丢失后的查询恢复、报价不可用不执行、结算不可用保存图片后重试不再生图、释放不可用后恢复、重开工具数据库后处理待完成操作、失去执行者的陈旧任务释放，以及仍由当前工作进程执行的任务不会仅按超时释放。

实际进程验证只使用启动器识别的 3200 / 3201 开发进程：工具停机时任务中心明确报告不可用；工具重启后已有任务、结果、会话和费用保留；平台停机时工具拒绝提交；平台重启后持久化身份和钱包恢复，不重复收费。未停止生产服务。

## 交付状态与限制

平台 http://192.168.6.111:3200 ，Yinglan 联调 http://192.168.6.111:3201 。二者仅监听此内网 IP，使用独立 dev-runtime 数据与模拟供应商，原开发配置继续保留。测试账号由受限 `dev-runtime/platform/test-accounts.json` 获取；验证会留下开发测试任务和账号，不涉及真实用户。

本版 OIDC 客户端、工具作用域和任务聚合是对 Yinglan 的受控注册。新增工具须同步平台注册代码与权限测试，不能靠上传一份工具清单自动接入。Python 客户端、远程 CI/分支保护和生产平台均未建设；本轮未推送任何仓库。

真实 SMTP、供应商效果/成本、生产域名与 HTTPS、生产用户和积分钱包迁移、生产备份与切换回滚，需下一轮独立实施。本轮开发通过不代表这些生产事项已验收。
