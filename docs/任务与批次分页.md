# 我的任务与兑换码批次分页（开发）

访问 <http://192.168.6.111:3200/workspace?view=tasks>；管理员在平台管理中选择「兑换码批次」。本轮仅开发；保留此前用户权限、主题和积分流水修改，仅重启 3200 开发平台且使用邮件捕获。没有操作生产、工具数据库、真实用户权限、真实邮件或付费接口。

## 我的任务

原来不断追加的「加载更多」改为每次只展示一页，默认 20 条，可选 20/50/100，显示当前页及本页条数，并提供上一页、下一页、刷新。刷新或调整页大小回到第一页；到达末页禁止下一页。页内容因删除而变为空时，自动退回有效的已访问页。

继续使用既有 `/api/v1/tasks?limit=20&cursor=...`，每次只请求一页，保存已访问页的起始游标以支持返回；不加载全量任务、不在前端切片。平台仍只通过工具 HTTP 接口按登录用户的 subject 汇总 Yinglan/Sanger；不直接读取工具数据。工具和任务类型按实际来源显示，Sanger 不再显示成 Yinglan 图片任务。

保持原工具来源顺序及每页排序语义，不增加跨工具全局时间排序。由于现有工具接口没有总数，任务页只显示当前页和条数，不推测总页数；跨页不是数据库快照。某工具暂不可用时明确显示工具名称、已读取任务和重试入口，暂停下一页以免跳过故障来源；可以重试当前页、返回上一页或刷新。

## 兑换码批次

新增 `/api/v1/admin/batches?page=1&page_size=20`，使用服务端 COUNT/LIMIT/OFFSET，显示总数、当前页/总页数、上一页/下一页，默认 20，可选 50/100。按 rowid 升序稳定排序，超界自动回到末页，空结果为第 1/1 页；名称/ID 关键词按字面量不区分大小写匹配，搜索或页大小变化回到第一页。

只对当前页批次计算兑换码张数、已兑换及已作废数，增加 `(batch_id,status)` 索引；零张数批次的统计为 0。保留批量生成、查看兑换码、复制整批和作废未用码，写入成功后刷新当前列表，保留已兑换记录。

契约先升级至兼容的 0.1.3，增加批次页码参数/响应与样例，再生成三方客户端及锁文件。不带 page 的旧 cursor/limit 仍可用，查看和复制整批继续复用旧兑换码接口；管理员、来源与 CSRF 防护不变。任务公共接口无需变更。

两处均提供读取中、空结果、错误和重试，加载时禁止重复翻页；搜索/页大小切换及离开组件后过期请求不能覆盖新列表。沿用现有深浅主题和手机局部表格滚动。

## 验证

平台 lint、类型检查、31 项测试、构建与契约检查；contracts 规范/样例测试和生成物漂移检查；Yinglan 生成客户端类型/契约检查；Sanger 生成 Python 客户端语法检查。

新增 `tests/tasks-batches.test.ts`：105 批次的跨页覆盖、20/50/100、旧游标兼容、状态统计、搜索/空结果、页码缩减、无效参数、游客/普通用户拒绝、作废保留已兑换码；通过模拟工具 HTTP 响应验证 107 条跨工具任务在三种页大小下无重复遗漏、工具/用户边界、空权限、坏游标和工具故障恢复。测试使用独立开发数据库，不连接真实工具或生产。

新增 `scripts/tasks-batches-smoke.ts`：实际 Microsoft Edge 桌面 1440×1000、手机视口 390×844。任务界面使用 107 条合成 HTTP 摘要，验证页码/条数、上一页/下一页、刷新、键盘、工具名称、错误重试、部分工具故障、请求竞态和空页回退。真实开发批次 API 使用 105 个随机前缀合成批次及本次生成的 1 个批次，验证分页、搜索、统计、查看/复制/生成/作废、末页收缩、错误重试、竞态、深浅主题和手机无页面溢出。结束后删除本次测试用户、会话、批次、兑换码及审计，不改已有开发数据。
