# 主题与工作台体验：开发改造与验收

开发入口：<http://192.168.6.111:3200/workspace>。本轮仅改开发代码、重启 3200 开发平台（邮件捕获模式）；没有操作生产实例、读取生产凭据、导入真实用户、调用付费接口或发送真实邮件。保留此前用户权限与分页开发修改。

## 可读性与主题

保持现有绿色视觉和布局，正文、说明、标签和表格改用统一文字颜色变量，浅色主题的辅助文字加深，表头及流水提示稍增字号。背景、面板、表单、工具卡片、弹窗、状态提示和边框共同适配深浅主题，首页与工作台均可切换。入口位于右上角，手机保留太阳/月亮图标及无障碍名称。

首次访问按系统主题，手动选择后以当前设备浏览器 `localStorage` 的 `biohub-theme` 保存。页面首屏绘制前在 head 应用选择，刷新及首页/工作台跳转保留主题；同来源标签页同步设置。未手动指定时随系统变化；存储被浏览器禁用时仍可切换当前页面，但不能跨刷新保存。主题只影响平台，不自动修改工具自己的外观。

## 工作台菜单与首页名称

原菜单使用 `location.assign`，每次点击整页重载，重新挂载认证加载页。改为在当前工作台内更新视图，通过 History API 同步地址；保留浏览器前进/后退、直接访问深层链接、刷新、旧链接、工具选择与 OIDC 登录流程。菜单切换收起手机导航，并将键盘焦点移到主内容。首次打开工作台仍正常检查会话，未登录不会看到账户内容。

侧栏「产品首页」改为「平台首页」，未登录工作台的返回入口也采用同一名称，链接仍指向 `/`。

## 积分流水

新增浏览器会话专用 `GET /api/v1/wallet/ledger?page=1&page_size=20`，只读取登录账号自己的流水，不接受 user_id。使用 SQLite COUNT、LIMIT/OFFSET 与账号索引，rowid 倒序，默认 20 条，可选 50/100；显示总数、当前页、上一页与下一页，越界页自动回到有效末页。保留每条流水的类型、原因、积分、剩余和有效期，以及原有到期记账语义。

流水提供加载、空结果、读取失败和重试；翻页期间禁用翻页按钮，修改页大小时回第一页；旧响应或离开页面后的响应不能覆盖新结果。领取每日积分或兑换后刷新余额和流水。固定数据集顺序稳定，跨请求不保证数据库快照。

契约先扩展至 0.1.2，再重新生成 platform、yinglan 和 sanger 客户端与锁定摘要。原 balance 不带参数继续返回最多 200 条流水；平台使用 `include_ledger=false` 只取余额规则和档位，流水由分页接口独立读取，避免每次顶部余额刷新携带一批流水。没有更改充值、扣款或授权业务语义。

## 实际验证

- 平台 `npm run lint`、`npm run typecheck`、`npm test`（26 项）、`npm run build`、`npm run contracts:check`。
- contracts `npm test` 与 `npm run check`；Yinglan 生成客户端类型及契约检查；Sanger 生成 Python 客户端语法检查。
- `scripts/navigation-smoke.ts`：8 项原有导航回归通过，包括工具选择、OIDC、深层链接、旧链接、手机菜单和退出。
- `scripts/admin-users-smoke.ts`：此前用户列表、权限弹窗、余额、状态与积分操作回归通过。
- 新增 `tests/ledger.test.ts`：205 条流水跨页无重复遗漏，20/50/100、超过原 200 条限制、旧余额兼容、账号隔离、游客/服务身份/指定其他用户拒绝、无效参数、空结果、删除后缩页、到期赠送记账及去重。
- 新增 `scripts/theme-ledger-smoke.ts`：实际 Microsoft Edge，桌面 1440×1000 和手机视口 390×844；确认菜单切换保持同一文档、加载页不重新出现、前进/后退正常；深浅主题切换、刷新、首页、标签页同步、系统变化、存储禁用、键盘操作；常用说明、导航及表格文字对比度至少 4.5:1；205 条流水分页、加载锁定、错误重试、过时响应、末页收缩与空结果，无页面溢出及浏览器异常。

主题/流水浏览器测试只创建一个无密码合成账号及其 205 条流水，退出后清理自身记录；用户管理回归的 105 个临时账号也自动清理。截图在 Git 忽略的 `test-results/platform-light-desktop.png`、`platform-dark-desktop.png`、`platform-home-dark.png`、`platform-credits-dark.png`、`platform-credits-light-mobile.png`、`platform-dark-mobile.png` 和 `platform-permissions-dark.png`，已复核外观。
